# Documentation instructions

The documents in this directory are the project record for product intent,
UX, data model, infrastructure choices, and investigated search improvements.

- Keep documents in Japanese unless the surrounding document uses English.
- Treat `abstract.md`, `ux.md`, `datamodel.md`, and `infrastructure.md` as
  decision records. Update them when implementation changes their stated
  behavior; do not leave an implemented feature described as future work.
- Use investigation documents to distinguish verified observations, proposed
  approaches, and unvalidated assumptions. Include relevant source paths or
  measurements where practical.
- Do not duplicate implementation details that belong in source comments or
  README setup instructions.
